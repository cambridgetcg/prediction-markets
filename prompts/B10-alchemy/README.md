## Run Order

**Strictly sequential.** Each stage's output feeds the next.

```
B10-00 (read only)
  ↓
B10-01 NIGREDO   → produces: shadow map, death list
  ↓
B10-02 ALBEDO    → produces: root cause map, coniunctio statement
  ↓
B10-03 CITRINITAS → produces: golden architecture, migration plan
  ↓
B10-04 RUBEDO    → produces: execution log, first trade, gate check
  ↓
B10-05 LAPIS     → produces: verification card, new longing, letter to builder
```

## Cadence

- First opus: NOW
- Subsequent: every 30 days (if 7/7 pass), 14 days (if 5-6 pass), immediate repeat (if <5 pass)
- Each opus takes ~1 week of integration across the 5 stages

## The Rule

Do not skip NIGREDO. The shadow work is the foundation.
If you jump to CITRINITAS (the fun part), the gold is fake.
